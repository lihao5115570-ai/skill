# MVP Roadmap

## Product Goal

Users upload a selfie. The system analyzes face shape, facial features, and personal style signals, then matches suitable beauty creators and explains how a creator's makeup can be adapted to the user's own face.

## MVP Steps

1. Project skeleton and service boundaries.
2. Selfie upload flow and backend upload API.
3. Analysis data model and mock analysis pipeline.
4. Beauty creator profile model and seed data.
5. Creator matching API.
6. Makeup migration guidance API.
7. Results page and basic user journey.

## Non-Goals For MVP

- Generic AI image generation tool.
- Full production-grade face recognition.
- Payment, community, or creator marketplace features.
